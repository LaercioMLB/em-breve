# Em Breve — Página inicial

>Página estática com design moderno mostrando "Em Breve".

## Como ver localmente

Opções rápidas:

1. Abrir `index.html` diretamente no navegador (duplo clique).
2. Ou rodar um servidor simples (recomendado para evitar problemas com fontes/paths):

No PowerShell (se tiver Python instalado):

```powershell
cd c:\Users\lbubi\Documents\GitHub\sos-construir-site
python -m http.server 8000
# depois abra http://localhost:8000 no navegador
```
